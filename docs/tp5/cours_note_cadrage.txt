1. DÉFINITION : QU’EST-CE QU’UNE NOTE DE CADRAGE ?
--------------------------------------------------------------------------------
Une note de cadrage est le document fondateur d’un projet. Elle pose les bases,
définit le périmètre, aligne les attentes et valide le lancement. C’est une
synthèse stratégique, non technique.

Elle répond aux questions QQOQCP :
* Quoi : ce que le projet va produire
* Pourquoi : le besoin, les enjeux
* Qui : acteurs, rôles, responsabilités
* Où : contexte, environnement
* Quand : planning, jalons
* Comment : moyens, ressources, contraintes
