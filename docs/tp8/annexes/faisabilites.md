## Solutions de Mitigation

### 1. Responsabilité Juridique (Substitution)
Indiquer clairement les produits sponsors/partenaires. Éviter les conflits d'intérêt.

### 2. Exigence Organisationnelle (Assistant)
Récolter feedback via likes, dislikes, "hors contexte" sur les messages pour amélioration continue.

### 3. Sensibilité Éthique (Assistant)
Cadrer strictement pour éviter dérive vers conseil médical. Mention légale obligatoire.
